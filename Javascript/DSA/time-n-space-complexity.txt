#### What is the the Time and Space Complexity of array methods(assuming an array contains n elements):
1.length: 
Time Complexity = O(1)
Space Complexity = O(1)


2.push:
Time Complexity = O(1)
Space Complexity = O(1)


3.pop:
Time Complexity = O(1)
Space Complexity = O(1)


4.shift:
Time Complexity = O(n)
Space Complexity = O(1)

5.unshift:
Time Complexity = O(n)
Space Complexity = O(1)


6.includes:
Time Complexity = O(n)
Space Complexity = O(1)

7.concat:
Time Complexity = O(n+m) = O(n)
Space Complexity = O(n+m) = O(n)

8.slice:
Time Complexity= O(k)
Space Complexity = O(k) // k = number of elements copied by slice().

#### What is the Time and Space Complexity of Object methods:
1.Keys:
Time Complexity = O(n) = O(n)
Space Complexity = O(n) = O(n)


2.Value: 
Time Complexity = O(n) = O(n)
Space Complexity = O(n) = O(n)


3.Entries:
Time Complexity = O(n) = O(n)
Space Complexity = O(n) = O(n)
